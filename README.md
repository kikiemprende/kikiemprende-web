# KikiEmprende

Sitio web oficial de KikiEmprende. Es una web estática, responsive y lista para publicar en Cloudflare Pages.

## Estructura

- `index.html`: contenido del sitio.
- `styles.css`: diseño para computador y celular.
- `main.js`: navegación móvil.
- `assets/`: imágenes optimizadas para la web.

## Publicación

En Cloudflare Pages no se requiere comando de construcción. El directorio de publicación es la raíz del repositorio.
